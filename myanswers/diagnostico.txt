0210: fallo por inconsistencia del generador original y por comparación del autocalificador
------------------------------------------------------------------------------------------

Archivo:
myanswers/answer-0210.py

Función:
detectar_outliers(df)

Estado:
La solución está implementada según el enunciado, pero el autocalificador se detiene por una inconsistencia del generador original.

Justificación:
El enunciado original solicita implementar una función llamada:

detectar_outliers(df)

La función debe:

1. Recibir un DataFrame con una columna `valores`.
2. Calcular Q1.
3. Calcular Q3.
4. Calcular el rango intercuartílico IQR.
5. Identificar valores menores que Q1 - 1.5 * IQR o mayores que Q3 + 1.5 * IQR.
6. Retornar un DataFrame con únicamente las filas consideradas outliers.

Mi solución implementa exactamente esa lógica:

- Calcula Q1 con `df["valores"].quantile(0.25)`.
- Calcula Q3 con `df["valores"].quantile(0.75)`.
- Calcula `iqr = q3 - q1`.
- Define los límites inferior y superior.
- Filtra el DataFrame.
- Retorna el DataFrame de outliers.

El problema aparece en el generador original de Valentina Garro, porque retorna:

return {"df": df}, None

Esto significa que, para el autocalificador:

- kwargs = {"df": df}
- expected_val = None

Cuando el autocalificador ejecuta mi solución, obtiene:

actual_val = detectar_outliers(df)

Ese `actual_val` es un DataFrame, porque eso es precisamente lo que pide el enunciado.

Luego el autocalificador intenta comparar:

compare_outputs(expected_val, actual_val)

Es decir, intenta comparar:

compare_outputs(None, DataFrame)

Como el comparador no tiene un caso especial para `expected_val = None` frente a `actual_val = DataFrame`, cae al bloque final de comparación, donde evalúa algo equivalente a:

if expected != actual:

En este caso, eso equivale a:

if None != DataFrame

En pandas, esa comparación no produce un único booleano, sino una estructura ambigua. Por eso se lanza el error:

ValueError: The truth value of a DataFrame is ambiguous. Use a.empty, a.bool(), a.item(), a.any() or a.all().

Conclusión para 0210:
La función solución es coherente con el enunciado original, pero el generador no proporciona un output esperado válido para comparar automáticamente. El error del autocalificador se produce porque el generador retorna `None` como salida esperada, aunque el enunciado pide retornar un DataFrame.

Referencias:
- myanswers/answer-0210.py, líneas 1-16.
- Generador original question-0002-usecase-generator.py de Valentina Garro, donde se construye el DataFrame y se retorna `return {"df": df}, None`.
- Enunciado original question-0002.txt de Valentina Garro, donde se solicita devolver un DataFrame que contenga únicamente las filas outliers.
- Autocalificador compartido por el profesor, especialmente la parte donde llama `actual_val = ans_funcs[0](**kwargs)` y luego compara con `compare_outputs(expected_val, actual_val)`.

Impacto del error 0210 sobre la validación completa

El error de 0210 hace que el autocalificador se detenga antes de continuar con las demás preguntas. Por eso, aunque `0464` está alineado con su generador y debería pasar, el Colab no alcanza a evaluarlo si primero se encuentra con la pregunta 0210.

Este comportamiento no implica que las demás soluciones estén incorrectas. Indica que el proceso de validación se interrumpe por una excepción generada durante la comparación del caso 0210.

------------------------------
No considero correcto modificar `answer-0210.py` para que retorne `None`, porque eso haría que la función contradiga el enunciado original. El enunciado pide devolver un DataFrame con outliers.
